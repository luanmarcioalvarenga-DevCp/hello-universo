# ✨ Hello Universo

![Java](https://img.shields.io/badge/Java-17%2B-ED8B00?logo=openjdk&logoColor=white) ![Swing](https://img.shields.io/badge/Java-Swing-2563EB)

Aplicação gráfica em **Java Swing** com campo de estrelas, efeito de profundidade, brilho pulsante e modo turbo. Inclui uma adaptação web em HTML, CSS e Canvas, preservando o código Java original.

## 🌌 Demonstração interativa

**[▶ Explorar Hello Universo no navegador](https://luanmarcioalvarenga-devcp.github.io/hello-universo/)**

> O link funciona após ativar o GitHub Pages na branch `main`, pasta `/ (root)`. A demonstração web está no arquivo [`index.html`](./index.html).

**Controles da versão web:** mova o mouse ou arraste para mudar a perspectiva; use os botões para pausar, ativar turbo e restaurar. Também é possível usar Espaço e T.

## 🎮 Controles
| Tecla / ação | Resultado |
|---|---|
| Mover o mouse | Altera a perspectiva |
| Espaço | Pausa ou continua |
| T | Ativa/desativa turbo |
| Esc | Fecha a janela |

## ▶️ Executar
Requer **JDK 17 ou superior**. No Windows, execute `executar.bat`. Alternativamente:

```bash
javac -encoding UTF-8 -d out src/HelloUniverso.java
java -cp out HelloUniverso
```

O programa abre uma janela gráfica. Não requer bibliotecas externas.

## 🧠 Conceitos praticados
Java Swing, temporizadores, eventos de teclado e mouse, projeção de coordenadas 3D em uma tela 2D e animação.
