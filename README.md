# ✨ Hello Universo

![Java](https://img.shields.io/badge/Java-17%2B-ED8B00?logo=openjdk&logoColor=white) ![Swing](https://img.shields.io/badge/Java-Swing-2563EB)

Aplicação gráfica em **Java Swing** com campo de estrelas, efeito de profundidade, brilho pulsante e modo turbo.

## 🎮 Controles
| Tecla / ação | Resultado |
|---|---|
| Mover o mouse | Altera a perspectiva |
| Espaço | Pausa ou continua |
| T | Ativa/desativa turbo |
| Esc | Fecha a janela |

## ▶️ Executar
Requer **JDK 17 ou superior**. No Windows, execute `executar.bat`. Alternativamente:

```bash
javac -encoding UTF-8 -d out src/HelloUniverso.java
java -cp out HelloUniverso
```

O programa abre uma janela gráfica. Não requer bibliotecas externas.

## 🧠 Conceitos praticados
Java Swing, temporizadores, eventos de teclado e mouse, projeção de coordenadas 3D em uma tela 2D e animação.
